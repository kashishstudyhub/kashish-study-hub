Unit 5: Matrices

Rank of Matrix

The rank of a matrix is the maximum number of linearly independent rows or columns.

Rank can be found using elementary row or column operations.

Rank(A) = number of non-zero rows in echelon form.

System of Linear Equations

A system of linear equations can be written in matrix form as:

AX = B

where A is the coefficient matrix, X is the variable matrix and B is the constant matrix.

Consistency

For the system AX = B:

The system is consistent if:

Rank(A) = Rank([A|B])

If Rank(A) ≠ Rank([A|B]), the system is inconsistent.

Eigenvalues

If A is a square matrix and X is a non-zero vector such that:

AX = λX

then λ is called an eigenvalue of matrix A.

Eigenvalues are obtained from:

|A - λI| = 0

Eigenvectors

A non-zero vector X satisfying:

AX = λX

is called an eigenvector corresponding to eigenvalue λ.

After finding λ, substitute it into:

(A - λI)X = 0

Diagonalization

A square matrix A is diagonalizable if it can be written as:

A = PDP⁻¹

Here D is a diagonal matrix containing eigenvalues and P contains corresponding eigenvectors.

Cayley-Hamilton Theorem

According to the Cayley-Hamilton theorem, every square matrix satisfies its own characteristic equation.

If the characteristic equation is:

p(λ) = 0

then:

p(A) = 0

This theorem can be used to find higher powers and inverse of a matrix.
