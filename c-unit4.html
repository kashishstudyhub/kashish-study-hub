1. Functions in C

A function is a block of statements designed to perform a particular task. Functions help divide a large program into smaller and manageable parts.

Advantages of Functions

  • Code becomes easier to understand.
  • Code can be reused.
  • Large programs can be divided into smaller modules.
  • Testing and debugging become easier.
  • Program structure becomes clearer.

Basic Function Syntax

return_type function_name(parameters)
{
    // statements
}

Example

#include <stdio.h>

void message()
{
    printf("Welcome to C Programming");
}

int main()
{
    message();

    return 0;
}
Exam Point:

A function may receive input through parameters and may return a value to the calling function.

2. Types of Functions

Functions in C can be classified according to whether they take arguments and whether they return a value.

Type Arguments Return Value
Type 1 No No
Type 2 Yes No
Type 3 No Yes
Type 4 Yes Yes

Example: Function with Arguments and Return Value

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result;

    result = add(10, 20);

    printf("Sum = %d", result);

    return 0;
}

3. Arguments and Parameters

A parameter is a variable listed in a function definition. An argument is the actual value supplied when the function is called.

Example

int add(int a, int b)
{
    return a + b;
}

int main()
{
    printf("%d", add(5, 10));

    return 0;
}

Here a and b are parameters, while 5 and 10 are arguments.

4. Return Values

The return statement sends a value from a function back to its caller. 

int square(int n)

Complete Example

5. Recursion

Recursion is a technique in which a function calls itself to solve a problem.

Important Parts of Recursion

  • Base Case: Condition that stops further calls.
  • Recursive Case: Part where the function calls itself.
Important:

A recursive function must have a suitable stopping condition. Otherwise, the function can continue calling itself indefinitely.

General Structure

void function()
{
    if(condition)
        return;

    function();
}

6. Recursion Programs

Program 1: Factorial Using Recursion

#include <stdio.h>

int factorial(int n)
{
    if(n == 0 || n == 1)
    {
        return 1;
    }

    return n * factorial(n - 1);
}

int main()
{
    int n;

    printf("Enter a number: ");
    scanf("%d", &n);

    printf("Factorial = %d", factorial(n));

    return 0;
}

Program 2: Sum of Natural Numbers Using Recursion

#include <stdio.h>

int sum(int n)
{
    if(n == 0)
    {
        return 0;
    }

    return n + sum(n - 1);
}

int main()
{
    int n;

    printf("Enter a number: ");
    scanf("%d", &n);

    printf("Sum = %d", sum(n));

    return 0;
}

Program 3: Fibonacci Using Recursion

#include <stdio.h>

int fibonacci(int n)
{
    if(n == 0)
        return 0;

    if(n == 1)
        return 1;

    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main()
{
    int n, i;

    printf("Enter number of terms: ");
    scanf("%d", &n);

    for(i = 0; i < n; i++)
    {
        printf("%d ", fibonacci(i));
    }

    return 0;
}

7. Introduction to Pointers

A pointer is a variable that stores the memory address of another variable.

Example

int x = 10;
int *p;

p = &x;

Here:

  • x stores the value 10.
  • &x gives the address of x.
  • p stores the address of x.
  • *p accesses the value stored at that address.

8. Address and Dereference Operators

Address Operator &

The & operator gives the memory address of a variable. 

int x = 10;

printf("%p", (void*)&x);

Dereference Operator *

The * operator can be used to access the value stored at the address held by a pointer. 

int x = 10;
int *p = &x;

printf("%d", *p);

9. Pointer Declaration

The general syntax for declaring a pointer is: 

data_type *pointer_name;

Examples

int *p;
char *c;
float *f;

The pointer type should be compatible with the type of object whose address it stores.

10. Important Pointer Programs

Program 1: Display Value Using Pointer

#include <stdio.h>

int main()
{
    int x = 25;
    int *p;

    p = &x;

    printf("Value = %d\n", x);
    printf("Value using pointer = %d", *p);

    return 0;
}

Program 2: Change Value Using Pointer

#include <stdio.h>

int main()
{
    int x = 10;
    int *p = &x;

    *p = 50;

    printf("New value = %d", x);

    return 0;
}

Program 3: Swap Two Numbers Using Pointers

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp;

    temp = *a;
    *a = *b;
    *b = temp;
}

int main()
{
    int x = 10;
    int y = 20;

    printf("Before swap: x = %d, y = %d\n", x, y);

    swap(&x, &y);

    printf("After swap: x = %d, y = %d", x, y);

    return 0;
}

11. Passing Arguments

Passing by Value

In passing by value, a function receives a copy of the argument. Changing the parameter does not directly change the original variable. 

#include <stdio.h>

void change(int x)
{
    x = 100;
}

int main()
{
    int a = 10;

    change(a);

    printf("%d", a);

    return 0;
}

Using Pointers to Modify the Caller’s Variable

A pointer can be passed to a function so that the function can access and modify the original object through its address. 

#include <stdio.h>

void change(int *x)
{
    *x = 100;
}

int main()
{
    int a = 10;

    change(&a);

    printf("%d", a);

    return 0;
}
