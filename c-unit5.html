1. Structure in C

A structure is a user-defined data type that allows related variables of different data types to be grouped together under one name.

Example

struct Student
{
    int roll;
    char name[50];
    float marks;
};
Example:

A Student may have a roll number, name and marks. These values have different data types but are related to the same student, so they can be grouped in a structure.

2. Structure Declaration

The general syntax of a structure is: 

struct structure_name
{
    data_type member1;
    data_type member2;
    data_type member3;
};

Example

struct Student
{
    int roll;
    char name[30];
    float marks;
};

A variable of this structure type can then be declared as: 

struct Student s1;

3. Structure Initialization

Structure members can be assigned values using the dot . operator. 

#include <stdio.h>

struct Student
{
    int roll;
    char name[30];
    float marks;
};

int main()
{
    struct Student s1;

    s1.roll = 101;

    printf("Enter name: ");
    scanf("%29s", s1.name);

    s1.marks = 85.5;

    printf("Roll = %d\n", s1.roll);
    printf("Name = %s\n", s1.name);
    printf("Marks = %.2f", s1.marks);

    return 0;
}
Important:

The dot operator is used to access members of a structure variable.

4. Array of Structures

An array of structures stores multiple structure variables of the same structure type.

Example

struct Student
{
    int roll;
    char name[30];
};

struct Student s[5];

Complete Program

#include <stdio.h>

struct Student
{
    int roll;
    char name[30];
};

int main()
{
    struct Student s[3];
    int i;

    for(i = 0; i < 3; i++)
    {
        printf("Enter roll number: ");
        scanf("%d", &s[i].roll);

        printf("Enter name: ");
        scanf("%29s", s[i].name);
    }

    printf("\nStudent Details:\n");

    for(i = 0; i < 3; i++)
    {
        printf("\nRoll = %d", s[i].roll);
        printf("\nName = %s\n", s[i].name);
    }

    return 0;
}

5. Nested Structures

A structure can contain another structure as one of its members. This is called a nested structure.

Example

struct Date
{
    int day;
    int month;
    int year;
};

struct Student
{
    int roll;
    char name[30];
    struct Date dob;
};

Here, Date is used inside the Student structure.

6. Union in C

A union is a user-defined data type similar to a structure, but its members share the same memory location.

Syntax

union Data
{
    int number;
    float value;
    char letter;
};

At a given time, a union object is intended to hold a value for one of its members.

Example

#include <stdio.h>

union Data
{
    int number;
    float value;
};

int main()
{
    union Data d;

    d.number = 10;

    printf("Number = %d", d.number);

    return 0;
}

7. Structure vs Union

Structure Union
Each member has separate storage within the object. Members share the same storage.
Members can hold values at the same time. One member value is normally meaningful at a time.
Size is related to the storage required by all members plus possible padding. Size is generally related to the largest member plus alignment.

8. File Handling in C

File handling allows a C program to store and retrieve data from external files.

Common File Operations

  • Open a file
  • Read data
  • Write data
  • Close the file

FILE Pointer

FILE *fp;

A FILE pointer is used by the standard C file I/O functions to refer to an open file stream.

9. File Opening Modes

Mode Purpose
r Open an existing file for reading.
w Open a file for writing; existing contents are replaced.
a Open a file for appending data at the end.
r+ Open an existing file for reading and writing.
w+ Open for reading and writing; existing contents are replaced.
a+ Open for reading and appending.

10. Writing to a File

The fopen() function opens a file. Always check whether the returned pointer is NULL before using the stream.

Example

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("notes.txt", "w");

    if(fp == NULL)
    {
        printf("File could not be opened.");
        return 1;
    }

    fprintf(fp, "Welcome to Kashish Study Hub.");

    fclose(fp);

    printf("Data written successfully.");

    return 0;
}

11. Reading from a File

A file opened in reading mode can be read using functions such as fgets() or fscanf().

Example using fgets()

#include <stdio.h>

int main()
{
    FILE *fp;
    char text[100];

    fp = fopen("notes.txt", "r");

    if(fp == NULL)
    {
        printf("File could not be opened.");
        return 1;
    }

    while(fgets(text, sizeof text, fp) != NULL)
    {
        printf("%s", text);
    }

    fclose(fp);

    return 0;
}
Important:

Always close an opened file with fclose() when you are finished using it.

14. Quick Revision

  • Structure: Groups related variables, potentially of different data types.
  • struct: Keyword used to define a structure.
  • Dot operator (.): Accesses a structure member.
  • Union: Members share the same storage.
  • FILE *: Pointer used with C file streams.
  • fopen(): Opens a file stream.
  • fclose(): Closes a file stream.
  • r: Read mode.
  • w: Write mode.
  • a: Append mode.
  • fgets(): Reads a line from a file stream.
  • fprintf(): Writes formatted data to a file stream.
