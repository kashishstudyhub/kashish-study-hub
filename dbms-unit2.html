Database Concepts, Relational Model, Keys and SQL

1. Database

A database is an organized collection of related data that can be stored, accessed and managed efficiently.

Example

A college database may contain student information such as:

  • Student ID
  • Student Name
  • Course
  • Semester
  • Marks
Exam Point: A database stores related information in an organized manner.

2. DBMS

DBMS stands for Database Management System. It is software used to create, store, retrieve, update and manage data in a database.

Functions of DBMS

  • Data storage
  • Data retrieval
  • Data modification
  • Data security
  • Backup and recovery
  • Data integrity

3. Relational Model

The relational model represents data using tables. A table consists of rows and columns.

Roll No Name Course
101 Rahul CSE
102 Priya CSE
103 Aman IT

Important Terms

  • Relation: Table
  • Tuple: Row
  • Attribute: Column
  • Domain: Set of valid values

4. Keys in DBMS

Keys are attributes or combinations of attributes used to identify records and establish relationships between tables.

Primary Key

A primary key uniquely identifies each record in a table. It cannot contain NULL values. 

CREATE TABLE Student
(
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50),
    Course VARCHAR(30)
);

Foreign Key

A foreign key is an attribute that refers to a key in another table. 

CREATE TABLE Marks
(
    RollNo INT,
    Marks INT,
    FOREIGN KEY (RollNo)
    REFERENCES Student(RollNo)
);

Other Important Keys

  • Candidate Key
  • Super Key
  • Alternate Key
  • Composite Key
  • Foreign Key

5. Integrity Constraints

Integrity constraints are rules that maintain the accuracy and consistency of data.

  • NOT NULL
  • UNIQUE
  • PRIMARY KEY
  • FOREIGN KEY
  • CHECK
  • DEFAULT
CREATE TABLE Student
(
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50) NOT NULL,
    Age INT CHECK(Age >= 17),
    City VARCHAR(30) DEFAULT 'Bhopal'
);

6. SQL

SQL stands for Structured Query Language. It is used to communicate with relational databases.

Major SQL Categories

  • DDL – Data Definition Language
  • DML – Data Manipulation Language
  • DQL – Data Query Language
  • DCL – Data Control Language
  • TCL – Transaction Control Language

7. DDL Commands

DDL stands for Data Definition Language. It is used to define or modify the structure of database objects.

CREATE

CREATE TABLE Student
(
    RollNo INT,
    Name VARCHAR(50),
    Marks INT
);

ALTER

ALTER TABLE Student
ADD City VARCHAR(30);

DROP

DROP TABLE Student;

8. DML Commands

DML stands for Data Manipulation Language. It is used to insert, update and delete data.

INSERT

INSERT INTO Student
VALUES (101, 'Rahul', 85);

UPDATE

UPDATE Student
SET Marks = 90
WHERE RollNo = 101;

DELETE

DELETE FROM Student
WHERE RollNo = 101;

9. DQL Commands

DQL is mainly used to retrieve data from a database. The most commonly used command is SELECT. 

SELECT * FROM Student;

Select Specific Columns

SELECT Name, Marks
FROM Student;

WHERE Clause

SELECT *
FROM Student
WHERE Marks > 80;
