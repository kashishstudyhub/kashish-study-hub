1. Structure in C

A structure is a user-defined data type that allows related variables of different data types to be grouped together under one name.

Example

struct Student
{
    int roll;
    char name[50];
    float marks;
};

Here, one student record can contain an integer roll number, a character array for the name and a floating-point marks value.

Exam Point:

Unlike an array, whose elements normally have the same data type, a structure can contain members of different data types.

2. Structure Declaration

The general syntax for declaring a structure is: 

struct structure_name
{
    data_type member1;
    data_type member2;
    data_type member3;
};

Example

struct Employee
{
    int id;
    char name[50];
    float salary;
};

Creating Structure Variables

struct Employee e1;

Here, e1 is a variable of type struct Employee.

3. Accessing Structure Members

The dot operator . is used to access a member of a structure variable. 

e1.id = 101;

printf("%d", e1.id);

Example

#include <stdio.h>

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main()
{
    struct Student s;

    s.roll = 1;
    s.marks = 85.5;

    printf("Roll = %d\n", s.roll);
    printf("Marks = %.2f", s.marks);

    return 0;
}

4. Structure Initialization

A structure variable can be initialized when it is declared. 

struct Student s = {1, "Kashish", 90.5};

Complete Example

#include <stdio.h>

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main()
{
    struct Student s = {1, "Kashish", 90.5};

    printf("Roll: %d\n", s.roll);
    printf("Name: %s\n", s.name);
    printf("Marks: %.2f", s.marks);

    return 0;
}

5. Array of Structures

An array of structures is used when we need to store records of multiple objects of the same structure type.

Declaration

struct Student students[5];

Example

#include <stdio.h>

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main()
{
    struct Student s[3];
    int i;

    for(i = 0; i < 3; i++)
    {
        printf("Enter roll number: ");
        scanf("%d", &s[i].roll);

        printf("Enter name: ");
        scanf("%49s", s[i].name);

        printf("Enter marks: ");
        scanf("%f", &s[i].marks);
    }

    printf("\nStudent Details\n");

    for(i = 0; i < 3; i++)
    {
        printf("\nRoll: %d", s[i].roll);
        printf("\nName: %s", s[i].name);
        printf("\nMarks: %.2f\n", s[i].marks);
    }

    return 0;
}

6. Pointer to Structure

A pointer to a structure stores the address of a structure variable.

Example

struct Student s;

struct Student *ptr;

ptr = &s;

The arrow operator -> is commonly used to access structure members through a pointer. 

ptr->roll = 10;

Complete Example

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

int main()
{
    struct Student s;
    struct Student *ptr = &s;

    ptr->roll = 10;
    ptr->marks = 88.5;

    printf("Roll = %d\n", ptr->roll);
    printf("Marks = %.2f", ptr->marks);

    return 0;
}

8. Union in C

A union is a user-defined type similar to a structure, but its members share the same memory storage.

Syntax

union union_name
{
    data_type member1;
    data_type member2;
};

Example

union Data
{
    int i;
    float f;
    char ch;
};
Important Difference:

In a union, the members share storage. Therefore, only one member's stored value should be treated as active at a time.

Union Example Program

#include <stdio.h>

union Data
{
    int number;
    float decimal;
    char character;
};

int main()
{
    union Data data;

    data.number = 100;

    printf("Number = %d", data.number);

    return 0;
}

9. Structure vs Union

Structure Union
Members have separate storage. Members share storage.
Several members can hold values at the same time. Only one member's stored value should be treated as active at a time.
Size is generally related to the combined storage requirements of its members plus alignment. Size is generally based on the largest member plus alignment.
Useful for records containing multiple pieces of information. Useful when different representations share the same storage.

10. File Handling in C

File handling allows a C program to store data in external files and read data from them.

Why File Handling is Used

  • To store data permanently.
  • To read previously stored information.
  • To write program output to a file.
  • To maintain records outside program memory.

FILE Pointer

FILE *fp;

The FILE pointer is used by standard C file functions to work with an opened file.

11. File Opening Modes

Mode Meaning
r Open an existing file for reading.
w Open for writing; creates a file or truncates an existing file.
a Open for appending; new data is written at the end.
r+ Open an existing file for reading and writing.
w+ Open for reading and writing; creates or truncates the file.
a+ Open for reading and appending.

12. fopen() and fclose()

fopen()

The fopen() function opens a file and returns a FILE pointer on success. 

FILE *fp;

fp = fopen("data.txt", "r");

Checking Whether File Opened

if(fp == NULL)
{
    printf("File could not be opened");
}

fclose()

The fclose() function closes an opened file. 

fclose(fp);
Good Practice:

After finishing file operations, close the file with fclose().

13. Reading and Writing Files

Writing Using fprintf()

FILE *fp;

fp = fopen("data.txt", "w");

if(fp != NULL)
{
    fprintf(fp, "Kashish Study Hub");
    fclose(fp);
}

Reading Using fscanf()

FILE *fp;
char word[50];

fp = fopen("data.txt", "r");

if(fp != NULL)
{
    fscanf(fp, "%49s", word);
    printf("%s", word);

    fclose(fp);
}

Character Based File Functions

fputc() writes a character to a file and fgetc() reads a character from a file. 

fputc('A', fp);

char ch;
ch = fgetc(fp);

14. Important File Handling Programs

Program 1: Write Data to a File

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("data.txt", "w");

    if(fp == NULL)
    {
        printf("Unable to open file");
        return 1;
    }

    fprintf(fp, "Welcome to Kashish Study Hub.\n");
    fprintf(fp, "C Programming Unit 5.");

    fclose(fp);

    printf("Data written successfully.");

    return 0;
}

Program 2: Read Data from a File

#include <stdio.h>

int main()
{
    FILE *fp;
    int ch;

    fp = fopen("data.txt", "r");

    if(fp == NULL)
    {
        printf("Unable to open file");
        return 1;
    }

    while((ch = fgetc(fp)) != EOF)
    {
        putchar(ch);
    }

    fclose(fp);

    return 0;
}

Program 3: Append Data to a File

#include <stdio.h>

int main()
{
    FILE *fp;

    fp = fopen("data.txt", "a");

    if(fp == NULL)
    {
        printf("Unable to open file");
        return 1;
    }

    fprintf(fp, "\nNew information added.");

    fclose(fp);

    printf("Data appended successfully.");

    return 0;
}

16. Quick Revision

  • Structure: Groups related variables of possibly different data types.
  • struct: Keyword used to define a structure.
  • . Used to access a member through a structure variable.
  • -> Used to access a member through a pointer to structure.
  • Union: Members share the same storage.
  • FILE *: File pointer used for file operations.
  • fopen(): Opens a file.
  • fclose(): Closes a file.
  • fprintf(): Writes formatted data to a file.
  • fscanf(): Reads formatted data from a file.
  • fgetc(): Reads a character from a file.
  • fputc(): Writes a character to a file.
  • EOF: Indicates end-of-file when returned by appropriate input functions.
