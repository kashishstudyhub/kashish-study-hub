2. Isometric Projection

Definition

Isometric projection is a method of representing a three- dimensional object on a two-dimensional plane in which the three principal axes make equal angles with the plane of projection.

Meaning of Isometric

The word isometric means equal measurement.

In an isometric drawing, the three principal directions are represented equally.

Isometric Axes

3. Isometric Axes

The three axes used in isometric projection are called isometric axes.

Three Isometric Directions

  • Vertical direction
  • 30° direction towards left
  • 30° direction towards right

The two horizontal isometric axes are generally drawn at 30° to the horizontal.

The vertical axis is perpendicular to the horizontal reference.

Important:

The angle between any two isometric axes is 120°.

4. Isometric Scale

Definition

An isometric scale is used when a true isometric projection is required. It converts the true length into the corresponding isometric length.

In isometric projection, lengths are reduced approximately to 0.816 of their true lengths.

Isometric Length ≈ 0.816 × True Length

Example

If the actual length of an object is 100 mm:

Isometric Length ≈ 0.816 × 100 = 81.6 mm

Isometric Scale Construction

5. Isometric View

An isometric view is a pictorial representation of an object in which three dimensions can be seen in a single drawing.

Features

  • Three dimensions are visible.
  • Vertical edges remain vertical.
  • Horizontal edges are generally drawn at 30°.
  • Parallel edges remain parallel.
  • It provides a pictorial appearance.

Isometric Cube

6. Isometric Representation of a Circle

A circle does not appear as a circle in an isometric view. It appears approximately as an ellipse.

Important

Circles on the three principal planes appear as ellipses with different orientations.

Isometric Ellipses

7. Methods of Drawing Isometric Views

Method 1: Box Method

The object is first enclosed inside an imaginary box. The required features are then transferred inside the box.

Method 2: Offset Method

Measurements are transferred from reference points along the isometric axes.

Method 3: Coordinate Method

The locations of points are determined using coordinates along the three isometric directions.

8. Box Method

  1. Study the given object carefully.
  2. Determine its overall length, width and height.
  3. Draw an isometric box of these dimensions.
  4. Locate important points inside the box.
  5. Draw inclined and vertical edges.
  6. Remove unnecessary construction lines.
  7. Darken the final visible outlines.

Isometric Box

9. Converting Orthographic Views into Isometric View

Orthographic views normally consist of front view, top view and side view. These views can be combined to create a pictorial isometric representation.

Procedure

  1. Study the front, top and side views.
  2. Determine length, width and height.
  3. Draw the three isometric axes.
  4. Construct the basic box.
  5. Transfer dimensions from orthographic views.
  6. Draw all visible edges.
  7. Represent circular features by ellipses.
  8. Remove hidden construction lines.
  9. Darken the final object.

Orthographic → Isometric

10. Converting Isometric View into Orthographic Views

An isometric drawing can be converted into separate front, top and side views.

Procedure

  1. Identify the three principal faces.
  2. Select the front face.
  3. Project its dimensions to obtain front view.
  4. Project the depth to obtain top view.
  5. Use the side dimensions for the side view.
  6. Show hidden details using proper conventions.

11. Introduction to CAD

CAD Meaning

CAD stands for Computer-Aided Design.

CAD is the use of computer software to create, modify, analyze and document engineering designs and drawings.

CAD is Used For

  • Engineering drawings
  • Mechanical design
  • Architectural drawings
  • Electrical layouts
  • Product design
  • Machine components
  • 3D modelling

12. Advantages of CAD

  • High drawing accuracy.
  • Fast creation of drawings.
  • Easy modification.
  • Easy duplication of objects.
  • Easy storage of drawings.
  • Easy sharing of drawings.
  • Reduces manual drafting work.
  • Improves productivity.
  • Supports 2D and 3D modelling.
  • Helps maintain drawing standards.

14. Basic Drawing Commands

Command Purpose
LINE Draws straight line segments.
CIRCLE Draws circles.
ARC Draws an arc.
POLYGON Creates regular polygons.
RECTANGLE Creates rectangular shapes.
ELLIPSE Creates an ellipse.
POLYLINE Creates connected line segments as one object.

15. LINE Command

The LINE command is used to create straight line segments between specified points.

General Steps

  1. Start the LINE command.
  2. Specify the first point.
  3. Specify the second point.
  4. Continue selecting points if required.
  5. Press Enter to finish.
LINE → First Point → Second Point → Enter

16. CIRCLE Command

The CIRCLE command is used to create a circle by specifying its centre and radius or diameter.

Method

  1. Start CIRCLE command.
  2. Specify centre point.
  3. Enter radius.
  4. Press Enter.
CIRCLE → Centre → Radius

CAD Circle

17. POLYGON Command

The POLYGON command creates regular polygons such as triangles, squares, pentagons and hexagons.

Examples

  • Triangle – 3 sides
  • Square – 4 sides
  • Pentagon – 5 sides
  • Hexagon – 6 sides
  • Octagon – 8 sides
POLYGON → Number of Sides → Centre → Size

18. Editing Commands

Editing commands are used to modify existing geometry.

Command Function
MOVE Moves an object from one location to another.
COPY Creates a duplicate of an object.
ROTATE Rotates an object around a base point.
MIRROR Creates a mirror image of an object.
ARRAY Creates multiple copies in a pattern.
TRIM Removes unwanted portions.
EXTEND Extends an object to meet another object.
OFFSET Creates a parallel or concentric copy.
SCALE Changes the size of an object.

19. MOVE Command

MOVE is used to change the position of an object without changing its size or orientation.

  1. Select MOVE.
  2. Select the object.
  3. Specify a base point.
  4. Specify the destination point.
MOVE → Select Object → Base Point → Destination

20. ROTATE Command

ROTATE changes the angular orientation of an object around a specified base point.

  1. Select ROTATE.
  2. Select the object.
  3. Specify the base point.
  4. Enter the required angle.
ROTATE → Object → Base Point → Angle
