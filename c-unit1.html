1. Introduction to C

C is a general-purpose programming language used for developing different types of software. It is also an important language for learning fundamental programming concepts.

Why Learn C?

  • It teaches fundamental programming concepts.
  • It helps understand variables and data types.
  • It provides a foundation for learning other languages.
  • It is useful for system-oriented programming.
  • It helps students understand memory-related concepts.
Exam Point:

C is a general-purpose, procedural programming language.

2. GCC / IDE Setup

To write and execute a C program, we need a C compiler or an Integrated Development Environment (IDE) that provides suitable editing and compilation tools.

What is GCC?

GCC stands for GNU Compiler Collection. It includes a compiler capable of compiling C programs.

Basic GCC Process

  1. Write the C source code.
  2. Save the file with a .c extension.
  3. Compile the program using a C compiler.
  4. Fix any compilation errors.
  5. Run the compiled program.

Example Commands

gcc program.c -o program

./program
Note:

The exact command for running a compiled program can differ depending on the operating system and environment.

Using an IDE

An IDE provides tools such as a code editor, compiler integration, error messages and program execution in one environment.

3. Hello World Program

The Hello World program is commonly used as the first program when learning a programming language. 

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Output

Hello World

Explanation

Code Meaning
#include <stdio.h> Includes declarations for standard input/output functions.
int main() Defines the main function where execution begins.
printf() Displays output.
return 0; Returns a status value from main.

4. Structure of a C Program

A C program can contain preprocessor directives, functions, declarations and executable statements.

General Structure

#include <stdio.h>

int main()
{
    /* declarations */

    /* statements */

    return 0;
}

Important Parts

  • Preprocessor directive: Used to include header files or perform preprocessing.
  • main(): The main function is the normal starting point of program execution.
  • Declarations: Used to declare variables and other objects.
  • Statements: Instructions that perform operations.
  • return: Can return a status value from a function such as main.

5. Data Types

A data type specifies the kind of value that a variable can store. This also helps the compiler determine how that data is represented and handled.

Important Basic Data Types

Data Type Purpose Example
int Stores whole numbers. 25
char Stores a character. 'A'
float Stores floating-point values. 25.5

Example

int age = 20;

char grade = 'A';

float marks = 85.5;
Important:

The exact size and range of a C data type can depend on the implementation. The sizeof operator can be used to check the size on a particular system.

6. Variables

A variable is a named object used to store a value. Its value can be changed during program execution.

Syntax

data_type variable_name;

Examples

int age;

char grade;

float marks;

Initialization

A variable can be given an initial value when it is declared. 

int age = 20;

char grade = 'A';

float marks = 85.5;

Rules for Variable Names

  • A variable name can contain letters, digits and underscore.
  • It should not begin with a digit.
  • Spaces are not allowed.
  • Keywords should not be used as variable names.
  • C identifiers are case-sensitive.
Valid examples:

age, student_name, marks1

Invalid examples:

2marks, student name

7. printf() Function

The printf() function is used to display formatted output. It is declared in the standard input/output header.

Simple Example

#include <stdio.h>

int main()
{
    printf("Welcome to C Programming");

    return 0;
}

Displaying a Variable

#include <stdio.h>

int main()
{
    int age = 20;

    printf("Age = %d", age);

    return 0;
}

8. scanf() Function

The scanf() function is commonly used to read formatted input from the user.

Example

#include <stdio.h>

int main()
{
    int age;

    printf("Enter your age: ");

    scanf("%d", &age);

    printf("Age = %d", age);

    return 0;
}

Why is & used?

For many ordinary scalar variables, scanf() needs the address where it should store the input value. The address-of operator & supplies that address.

Remember: 
scanf("%d", &age);

9. Format Specifiers

Format specifiers tell formatted input/output functions how a value should be interpreted or displayed.

Specifier Common Use Example
%d int printf("%d", age);
%c char printf("%c", grade);
%f float printf("%f", marks);
%lf double in scanf() scanf("%lf", &x);
%s String printf("%s", name);

10. Important Programs

Program 1: Display Student Information

#include <stdio.h>

int main()
{
    int age = 20;
    char grade = 'A';
    float marks = 85.5;

    printf("Age = %d\n", age);
    printf("Grade = %c\n", grade);
    printf("Marks = %.2f\n", marks);

    return 0;
}

Program 2: Input and Display Integer

#include <stdio.h>

int main()
{
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    printf("You entered: %d", number);

    return 0;
}

Program 3: Add Two Numbers

#include <stdio.h>

int main()
{
    int a, b, sum;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    sum = a + b;

    printf("Sum = %d", sum);

    return 0;
}

Program 4: Calculate Average

#include <stdio.h>

int main()
{
    float a, b, c, average;

    printf("Enter three numbers: ");
    scanf("%f %f %f", &a, &b, &c);

    average = (a + b + c) / 3.0f;

    printf("Average = %.2f", average);

    return 0;
}

Program 5: Calculate Area of Circle

#include <stdio.h>

int main()
{
    float radius, area;

    printf("Enter radius: ");
    scanf("%f", &radius);

    area = 3.14159f * radius * radius;

    printf("Area = %.2f", area);

    return 0;
}
