1. Introduction to Orthographic Projection

What is Projection?

Projection is the process of representing a three-dimensional object on a two-dimensional drawing surface.

In engineering graphics, projection is used to obtain accurate views of objects such as their front view, top view and side view.

What is Orthographic Projection?

Orthographic projection is a method of representing an object by drawing perpendicular projectors from the object to the plane of projection.

Main Projection Planes

  • Horizontal Plane (HP): Used mainly for top view.
  • Vertical Plane (VP): Used mainly for front view.
  • Profile Plane: Used for side view.

HP and VP

Reference Line XY

The line XY represents the intersection of the Horizontal Plane and Vertical Plane. It is used as the reference line for drawing projections.

2. Principles of Orthographic Projection

  1. The object is assumed to be placed in a definite position with respect to HP and VP.
  2. Projectors are drawn perpendicular to the plane of projection.
  3. The front view is obtained on VP.
  4. The top view is obtained on HP.
  5. The views are arranged according to the selected projection method.
  6. All projections should be accurate and properly aligned.

Advantages

  • Provides accurate dimensions.
  • Shows the exact shape of surfaces.
  • Useful for manufacturing.
  • Provides standardized engineering representation.
  • Helps in understanding three-dimensional objects.

3. First Angle Projection

Definition

In first angle projection, the object is placed in the first quadrant, that is, above HP and in front of VP.

Position of Object

  • Object is above HP.
  • Object is in front of VP.

Arrangement of Views

In first angle projection, the view is placed on the opposite side of the object.

  • Top view appears below the front view.
  • Right side view appears on the left side.
  • Left side view appears on the right side.

First Angle Projection Arrangement

Remember:

In First Angle Projection, the top view is below the front view.

4. Third Angle Projection

Definition

In third angle projection, the object is placed in the third quadrant, that is, below HP and behind VP.

Arrangement of Views

  • Top view appears above the front view.
  • Right side view appears on the right side.
  • Left side view appears on the left side.

Third Angle Projection Arrangement

First Angle Third Angle
Top view below front view Top view above front view
Right view on left Right view on right
Object lies in first quadrant Object lies in third quadrant

6. Projection of Points

A point is represented by its front view and top view. The position of these views depends on the location of the point with respect to HP and VP.

Point in First Quadrant

A point is above HP and in front of VP.

Its front view is above XY and its top view is below XY.

Point A in First Quadrant

Notation

The front view of point A is generally represented as a', while the top view is represented as a.

8. Projection of Straight Lines

Definition

Projection of a straight line means obtaining the projections of both endpoints of the line on HP and VP and joining their corresponding projections.

Important Cases

  1. Line parallel to both HP and VP.
  2. Line perpendicular to HP and parallel to VP.
  3. Line perpendicular to VP and parallel to HP.
  4. Line inclined to HP and parallel to VP.
  5. Line inclined to VP and parallel to HP.
  6. Line inclined to both HP and VP.

9. Line Parallel to Both HP and VP

When a line is parallel to both HP and VP, its front view and top view are parallel to XY.

Result

  • Front view shows true length.
  • Top view shows true length.
  • Both views are parallel to XY.

Line Parallel to HP and VP

10. Line Inclined to HP and Parallel to VP

In this case the line is inclined at an angle to HP but remains parallel to VP.

Characteristics

  • Front view shows the true length.
  • Front view makes the true inclination with XY.
  • Top view is shorter than the true length.
  • Top view is generally parallel to XY.
True Length = Front View Length

Construction Procedure

  1. Draw the reference line XY.
  2. Mark the first endpoint.
  3. Draw the true length at the given inclination to XY.
  4. Project both endpoints downward to HP.
  5. Join the top-view points.
  6. Mark the required dimensions.

Line Inclined to HP

11. Line Inclined to VP and Parallel to HP

In this case the line is inclined to VP but remains parallel to HP.

Characteristics

  • Top view shows true length.
  • Top view shows true inclination.
  • Front view is shorter.
  • Front view is generally parallel to XY.
True Length = Top View Length

Construction Procedure

  1. Draw XY reference line.
  2. Draw the true length in top view at the given angle.
  3. Project its endpoints upward to VP.
  4. Join the front-view points.
  5. Complete the dimensions.

Line Inclined to VP

12. Line Inclined to Both HP and VP

This is one of the most important cases in engineering graphics. Here the line is inclined to both reference planes.

Characteristics

  • Neither front view nor top view shows true length.
  • Both projections are shorter than the true length.
  • True length must be obtained by an appropriate construction.
  • The line has two true inclinations.

Symbols

Let:

θ = True inclination with HP
φ = True inclination with VP

General Construction Method

  1. Draw the XY reference line.
  2. Draw the initial position of the line.
  3. Project its endpoints onto HP and VP.
  4. Obtain the apparent front and top views.
  5. Use rotation / auxiliary construction to determine true length.
  6. Measure the true angles with reference planes.

Line Inclined to Both HP and VP

13. True Length of a Line

Definition

The actual length of a line in space is called its true length.

If a line is inclined to both HP and VP, its projected lengths are smaller than its actual length.

When is True Length Visible?

Position of Line True Length Visible In
Parallel to HP Top View
Parallel to VP Front View
Inclined to HP only Front View
Inclined to VP only Top View
Inclined to both Neither direct view
Important:

A projection generally shows true length only when the line is parallel to that particular plane of projection.

14. True Inclination

The angle made by a line with a reference plane is called its true inclination with that plane.

Types

  • θ (Theta): Inclination with HP.
  • φ (Phi): Inclination with VP.
θ = True Angle with HP
φ = True Angle with VP

Apparent Inclination

The angle observed in a projection is called apparent inclination. It may not be equal to the true inclination when the line is inclined to both planes.
