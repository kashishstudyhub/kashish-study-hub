Unit 3: Sequences and Series

Sequence

A sequence is an ordered list of numbers arranged according to a definite rule.

Example: 1, 2, 3, 4, 5, ...

The general term is usually represented by aₙ.

Convergence

A sequence converges if its terms approach a finite definite value as n approaches infinity.

A series is convergent if its sequence of partial sums approaches a finite value.

Tests of Convergence

Important tests include:

  • Comparison Test
  • Limit Comparison Test
  • Ratio Test
  • Root Test
  • Integral Test
  • Alternating Series Test

These tests help determine whether an infinite series is convergent or divergent.

Power Series

A power series generally has the form:

Σ aₙ(x-c)ⁿ

Here c is the center of the power series.

The interval and radius of convergence can be determined using convergence tests.

Taylor's Series for Two Variables

For a function f(x,y), Taylor expansion can be written around a point (a,b).

f(x,y) can be expanded using partial derivatives with respect to x and y.

It is useful for approximating functions of two variables.

Elementary Function Expansions

Important expansions include:

eˣ = 1 + x + x²/2! + x³/3! + ...

sin x = x - x³/3! + x⁵/5! - ...

cos x = 1 - x²/2! + x⁴/4! - ...

log(1+x) = x - x²/2 + x³/3 - ...

Fourier Series

Fourier series represents a periodic function as a sum of sine and cosine functions.

General form:

f(x) = a₀/2 + Σ[aₙ cos(nx) + bₙ sin(nx)]

It is widely used in mathematics, physics and engineering.

Parseval's Theorem

Parseval's theorem establishes a relationship between a function and its Fourier coefficients.

It is useful for calculating sums and integrals involving Fourier series.
