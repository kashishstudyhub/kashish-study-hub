1. 🌐 MAC Sublayer

MAC stands for Media Access Control. It is a sublayer of the Data Link Layer.

The main purpose of the MAC sublayer is to control how multiple devices access and share a common communication medium.

Main Functions

  • Controls access to the shared medium.
  • Uses MAC addresses for link-level identification.
  • Helps coordinate transmissions.
  • Deals with collisions in contention-based networks.
Exam Point:

MAC Sublayer = Controls access to the communication medium.

2. 🏷️ MAC Addressing

A MAC address is a link-layer address associated with a network interface.

It is used to identify network interfaces for communication on the local network.

Important Features

  • Associated with a network interface.
  • Used at the Data Link Layer.
  • Helps identify the source and destination at the link level.
Example format:

A MAC address is commonly written as groups of hexadecimal digits, for example:

00:1A:2B:3C:4D:5E

3. ⚔️ Contention-Based Protocols

In contention-based protocols, multiple stations compete for access to a shared communication channel.

When two or more stations transmit at the same time, a collision can occur in protocols where simultaneous transmission is not allowed.

Important Protocols

  • ALOHA
  • CSMA
  • CSMA/CD
  • CSMA/CA

4. 📡 ALOHA

ALOHA is a contention-based medium access protocol. A station transmits when it has data to send.

If transmissions overlap and a collision occurs, the affected frame can be retransmitted after a waiting period.

Types of ALOHA

  • Pure ALOHA
  • Slotted ALOHA
Exam Tip:

Pure ALOHA allows transmission at any time, whereas Slotted ALOHA restricts transmission to defined time slots.

5. 📤 Pure ALOHA

In Pure ALOHA, a station can transmit whenever it has a frame ready.

Working

  1. Station prepares a frame.
  2. Station transmits the frame.
  3. If no collision occurs, transmission succeeds.
  4. If a collision occurs, the station waits for a random period.
  5. The frame can then be retransmitted.

Advantages

  • Simple concept.
  • Easy to implement.

Disadvantages

  • Collisions can occur frequently.
  • Channel utilization can be low under heavy load.

6. ⏱️ Slotted ALOHA

In Slotted ALOHA, time is divided into equal slots and a station can begin transmission only at the beginning of a slot.

Working

  1. Time is divided into slots.
  2. Station waits for the beginning of a slot.
  3. Station transmits its frame.
  4. If collision occurs, retransmission is attempted later.

Difference Between Pure and Slotted ALOHA

Pure ALOHA Slotted ALOHA
Transmission can begin at any time. Transmission begins only at slot boundaries.
Higher possibility of overlapping transmissions. Timing reduces the vulnerable period.
Simple timing requirement. Requires synchronization of time slots.

7. 👂 CSMA

CSMA stands for Carrier Sense Multiple Access.

Before transmitting, a station senses the communication channel to determine whether another transmission is already taking place.

Basic Working

  1. Station senses the channel.
  2. If the channel is suitable, it attempts transmission.
  3. If the channel is busy, the station waits according to the protocol.
  4. Transmission is attempted again later.
Easy Meaning:

CSMA = "Transmit karne se pehle channel ko check karo."

8. 💥 CSMA/CD

CSMA/CD stands for Carrier Sense Multiple Access with Collision Detection.

It combines carrier sensing with collision detection.

Basic Working

  1. Station senses the channel.
  2. If the channel is free, transmission begins.
  3. While transmitting, the station monitors for collision.
  4. If a collision is detected, the transmission is stopped or handled according to the protocol.
  5. The station waits for a backoff period.
  6. Transmission is attempted again.

Key Idea

CSMA/CD detects collisions after they occur.

9. 🛡️ CSMA/CA

CSMA/CA stands for Carrier Sense Multiple Access with Collision Avoidance.

It attempts to reduce the chance of collision before transmission.

Basic Working

  1. Station senses the channel.
  2. If the channel is busy, it waits.
  3. If the channel is suitable, the station uses the required waiting/backoff mechanism.
  4. Transmission is then attempted.

CSMA/CD vs CSMA/CA

CSMA/CD CSMA/CA
Collision Detection Collision Avoidance
Detects collision during transmission. Attempts to reduce collisions before transmission.

10. 🔢 Binary Exponential Backoff (BEB)

Binary Exponential Backoff is a backoff technique used after collisions.

After repeated collisions, the range from which a station selects its waiting time becomes larger.

Basic Idea

  • Collision occurs.
  • Station waits for a random backoff period.
  • If another collision occurs, the possible waiting range increases.
  • This process continues according to the protocol.
Remember:

More collisions → larger possible backoff range.

11. 🚫 Collision-Free Protocols

Collision-free protocols are designed to organize access to the shared communication medium so that simultaneous transmissions do not result in collisions.

Main Idea

Instead of allowing stations to freely compete at the same time, access is coordinated according to a defined method.

Examples of Approaches

  • Reservation-based access
  • Controlled access
  • Token-based access

12. ⚖️ Limited Contention Protocols

Limited contention protocols attempt to combine the advantages of contention-based access with controlled access.

The main objective is to reduce collisions while maintaining efficient use of the shared channel.

Main Idea

  • Stations contend for access.
  • Contention is controlled or limited.
  • Collision probability can be reduced.
  • Channel utilization can be improved.
