1. Functions in C

A function is a block of statements that performs a particular task. Functions help divide a large program into smaller and manageable parts.

Advantages of Functions

  • Reduces repetition of code.
  • Makes programs easier to understand.
  • Makes debugging easier.
  • Allows code reuse.
  • Divides a large program into smaller modules.

Basic Syntax

return_type function_name(parameters)
{
    statements;
}

Example

#include <stdio.h>

void message()
{
    printf("Welcome to Kashish Study Hub");
}

int main()
{
    message();

    return 0;
}

2. Types of Functions

Functions can be classified according to whether they take arguments and whether they return a value.

Type Arguments Return Value
Type 1 No No
Type 2 Yes No
Type 3 No Yes
Type 4 Yes Yes

Example

#include <stdio.h>

int add(int a,int b)
{
    return a+b;
}

int main()
{
    int result;

    result=add(10,20);

    printf("Sum = %d",result);

    return 0;
}

3. Arguments and Parameters

A parameter is a variable used in the function definition. An argument is the actual value supplied when the function is called. 

int add(int a,int b)
{
    return a+b;
}

int main()
{
    printf("%d",add(5,10));

    return 0;
}
Example:

In add(5,10), 5 and 10 are arguments. In int add(int a,int b), a and b are parameters.

4. Return Statement

The return statement sends a value from a function back to the calling function. 

int square(int n)
{
    return n*n;
}

Complete Program

#include <stdio.h>

int square(int n)
{
    return n*n;
}

int main()
{
    int result;

    result=square(5);

    printf("Square = %d",result);

    return 0;
}

5. Recursion

Recursion is a technique in which a function calls itself. It is useful for solving problems that can be divided into smaller similar problems.

Two Important Parts

  • Base Case: Condition that stops recursion.
  • Recursive Case: Part in which the function calls itself.
Important:

A recursive function needs an appropriate stopping condition. Without one, recursive calls may continue indefinitely.

Basic Example

void count(int n)
{
    if(n==0)
        return;

    printf("%d ",n);

    count(n-1);
}

6. Factorial Using Recursion

The factorial of a positive integer n is the product of all positive integers from 1 to n.

For example:

5! = 5 × 4 × 3 × 2 × 1 = 120

Program

#include <stdio.h>

int factorial(int n)
{
    if(n==0 || n==1)
    {
        return 1;
    }

    return n*factorial(n-1);
}

int main()
{
    int n;

    printf("Enter a number: ");

    scanf("%d",&n);

    printf("Factorial = %d",factorial(n));

    return 0;
}

7. Pointers

A pointer is a variable that stores the memory address of another object.

Example

int x=10;

int *p;

p=&x;

Here:

  • x contains the value 10.
  • &x gives the address of x.
  • p stores the address of x.
  • *p accesses the value stored at that address.

Pointer Declaration

data_type *pointer_name;

Examples

int *p;

char *c;

float *f;

8. Pointer Operators

Address Operator (&)

The & operator is used to obtain the address of an object. 

int x=10;

printf("%p",(void*)&x);

Dereference Operator (*)

The * operator can be used with a pointer expression to access the object stored at that address. 

int x=10;

int *p=&x;

printf("%d",*p);

9. Pointer Program

Display Value Using Pointer

#include <stdio.h>

int main()
{
    int x=25;

    int *p=&x;

    printf("Value = %d\n",x);

    printf("Value using pointer = %d",*p);

    return 0;
}

Change Value Using Pointer

#include <stdio.h>

int main()
{
    int x=10;

    int *p=&x;

    *p=50;

    printf("New value = %d",x);

    return 0;
}

10. Swap Two Numbers Using Pointers

Pointers can be passed to a function so the function can modify the original objects through their addresses.

Program

#include <stdio.h>

void swap(int *a,int *b)
{
    int temp;

    temp=*a;

    *a=*b;

    *b=temp;
}

int main()
{
    int x=10;
    int y=20;

    printf("Before Swap:\n");

    printf("x=%d y=%d\n",x,y);

    swap(&x,&y);

    printf("After Swap:\n");

    printf("x=%d y=%d",x,y);

    return 0;
}
