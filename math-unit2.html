Unit 2: Calculus-II & Multivariable Calculus

Definite Integrals as Limits of Sums

A definite integral can be defined as the limit of a sum:

∫ₐᵇ f(x) dx = lim(n→∞) Σ f(xᵢ) Δx

It is used to calculate area under a curve between two limits.

Beta Function

The Beta function is defined as:

B(m,n) = ∫₀¹ xᵐ⁻¹(1-x)ⁿ⁻¹ dx

Relation with Gamma function:

B(m,n) = Γ(m)Γ(n) / Γ(m+n)

Gamma Function

Gamma function is defined as:

Γ(n) = ∫₀∞ e⁻ˣ xⁿ⁻¹ dx

For positive integers:

Γ(n) = (n - 1)!

Area Under Curves

The area between a curve y = f(x) and the x-axis from x = a to x = b is:

Area = ∫ₐᵇ f(x) dx

Volume of Solids

Integration can be used to calculate the volume of solids.

Volume = π ∫ₐᵇ y² dx

This formula is commonly used for solids formed by revolution.

Partial Differentiation

When a function has two or more independent variables, differentiation with respect to one variable while keeping others constant is called partial differentiation.

If z = f(x,y), then:

∂z/∂x and ∂z/∂y

Euler's Theorem

If z is a homogeneous function of degree n, then:

x(∂z/∂x) + y(∂z/∂y) = nz

Total Derivatives

If z = f(x,y), where x and y depend on t, then:

dz/dt = (∂z/∂x)(dx/dt) + (∂z/∂y)(dy/dt)

Lagrange's Multipliers

Lagrange's multiplier method is used to find maximum or minimum values of a function subject to a constraint.

For f(x,y) subject to g(x,y) = 0:

∇f = λ∇g

This method is useful for constrained maxima and minima problems.
