1. 🎯 Network Goals

A computer network is a collection of interconnected computers and devices that communicate with each other and share information and resources.

Main Goals of Computer Networks

  • Resource Sharing: Hardware, software and information can be shared between connected systems.
  • Communication: Users can communicate and exchange information.
  • Information Sharing: Data can be transferred between different systems.
  • Reliability: Network systems can improve availability of services and information.
  • Scalability: Networks can be expanded by adding additional devices and resources.
  • Efficient Resource Utilization: Network resources can be utilized by multiple users.
Exam Point:

The major goals of networking include communication, resource sharing, information sharing, reliability and scalability.

2. 🏗️ Network Architecture

Network architecture describes the overall organization of network components, communication protocols and services.

Important Elements

  • Network devices
  • Communication links
  • Protocols
  • Services
  • Layered organization
Simple Example:

When a computer sends data to another computer, different network layers perform different tasks to make communication possible.

3. 🌐 Network Classification

Networks can be classified according to their geographical coverage and purpose.

Network Full Form Coverage
PAN Personal Area Network Very small personal area
LAN Local Area Network Building, room or campus
MAN Metropolitan Area Network City or metropolitan area
WAN Wide Area Network Large geographical area

PAN

Personal Area Network is designed for communication among devices around an individual user.

LAN

Local Area Network connects devices within a relatively small geographical area such as a room, building or campus.

MAN

Metropolitan Area Network covers a larger area such as a city.

WAN

Wide Area Network connects systems over large geographical distances.

4. 📡 Protocol Hierarchy

A protocol is a set of rules that determines how communication takes place between network entities.

In a layered network architecture, network functions are divided into multiple layers.

Advantages of Layering

  • Reduces complexity
  • Makes network design easier
  • Allows independent development of layers
  • Makes troubleshooting easier
  • Provides standardization
Remember:

Each layer provides services to the layer above it and uses services of the layer below it.

5. 🔗 Connection-Oriented & Connectionless Services

Connection-Oriented Service

In a connection-oriented service, a logical connection is established before data transfer begins.

Three Basic Phases

  1. Connection Establishment
  2. Data Transfer
  3. Connection Termination
Example:

It is similar to establishing a communication session before exchanging information.

Connectionless Service

In a connectionless service, data can be sent without establishing a connection first.

Each data unit can be handled independently.

Difference

Connection-Oriented Connectionless
Connection is established first No prior connection establishment
Has establishment and termination phases Does not require these phases
Suitable when session-based communication is needed Suitable when independent data transfer is sufficient

6. ⚙️ Service Primitives

Service primitives are operations through which a layer requests or receives a service from another layer.

Primitive Purpose
LISTEN Wait for an incoming connection
CONNECT Request establishment of a connection
SEND Send information
RECEIVE Receive information
DISCONNECT Terminate a connection
Exam Point:

LISTEN, CONNECT, SEND, RECEIVE and DISCONNECT are commonly used service primitive operations.

7. 🧩 ISO-OSI Reference Model

The OSI (Open Systems Interconnection) reference model organizes network communication into seven layers.

No. Layer Main Function
7 Application Provides network services to applications
6 Presentation Handles data representation and translation
5 Session Manages communication sessions
4 Transport Provides transport and end-to-end communication services
3 Network Logical addressing and routing
2 Data Link Framing and link-level control
1 Physical Transmission of bits over the physical medium

Layer 1 – Physical Layer

The Physical Layer is concerned with transmitting raw bits over a physical communication medium.

Layer 2 – Data Link Layer

The Data Link Layer deals with frames and communication over a single link. It includes functions such as framing, flow control and error control.

Layer 3 – Network Layer

The Network Layer is responsible for logical addressing and routing packets between networks.

Layer 4 – Transport Layer

The Transport Layer provides communication services between application processes and supports end-to-end transport functions.

Layer 5 – Session Layer

The Session Layer manages communication sessions between applications.

Layer 6 – Presentation Layer

The Presentation Layer deals with data representation, translation and related formatting functions.

Layer 7 – Application Layer

The Application Layer provides network-related services directly to application software.

🧠 Easy Order to Remember:

Application → Presentation → Session → Transport → Network → Data Link → Physical
