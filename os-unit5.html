1. Structure in C

A structure is a user-defined data type that allows us to group different types of data under one name.

For example, information about a student may contain a name, roll number and marks. These can be grouped using a structure.

Basic Syntax

struct Student
{
    int roll;
    char name[50];
    float marks;
};
Important:

The members of a structure can have different data types.

2. Structure Declaration

Example

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main()
{
    struct Student s1;

    return 0;
}

Here s1 is a structure variable of type struct Student.

3. Structure Initialization

A structure variable can be initialized when it is declared. 

struct Student
{
    int roll;
    char name[20];
    float marks;
};

int main()
{
    struct Student s1 = {101, "Kashish", 85.5};

    return 0;
}

Accessing Members

The dot . operator is used to access members of a structure variable. 

printf("%d",s1.roll);

printf("%s",s1.name);

printf("%.2f",s1.marks);

4. Array of Structures

An array of structures stores multiple structure variables of the same structure type.

Example

struct Student
{
    int roll;
    char name[30];
    float marks;
};

struct Student s[3];

Complete Program

#include <stdio.h>

struct Student
{
    int roll;
    char name[30];
    float marks;
};

int main()
{
    struct Student s[3];
    int i;

    for(i=0;i<3;i++)
    {
        printf("Enter roll number: ");
        scanf("%d",&s[i].roll);

        printf("Enter name: ");
        scanf("%29s",s[i].name);

        printf("Enter marks: ");
        scanf("%f",&s[i].marks);
    }

    printf("\nStudent Details:\n");

    for(i=0;i<3;i++)
    {
        printf("\nRoll = %d",s[i].roll);
        printf("\nName = %s",s[i].name);
        printf("\nMarks = %.2f\n",s[i].marks);
    }

    return 0;
}

5. Pointer to Structure

A pointer can store the address of a structure variable. 

struct Student
{
    int roll;
    float marks;
};

int main()
{
    struct Student s = {101, 90.5};

    struct Student *ptr;

    ptr = &s;

    printf("%d",ptr->roll);

    printf("%.2f",ptr->marks);

    return 0;
}
Exam Point:

The arrow operator -> is commonly used to access structure members through a pointer.

7. Union in C

A union is a user-defined data type similar to a structure, but its members share the same memory location.

Syntax

union Data
{
    int i;
    float f;
    char c;
};

Example

#include <stdio.h>

union Data
{
    int i;
    float f;
    char c;
};

int main()
{
    union Data d;

    d.i=10;

    printf("Integer = %d",d.i);

    return 0;
}
Important Difference:

In a structure, each member generally has its own storage. In a union, members share the same storage.

8. Structure vs Union

Structure Union
Members have separate storage. Members share storage.
Multiple members can hold values simultaneously. Only one member's stored value should be treated as current at a time.
Size is related to the storage required by all members, subject to padding. Size is related to the largest member, subject to alignment.

9. File Handling in C

File handling is used to store and retrieve data from external files. It allows a program to work with data that can remain available after the program ends.

File Pointer

FILE *fp;

The FILE type is used by the C standard library to represent a stream associated with a file.

Basic Steps

  1. Declare a file pointer.
  2. Open the file.
  3. Read from or write to the file.
  4. Close the file.

10. File Opening Modes

Mode Meaning
r Open an existing file for reading.
w Open a file for writing; existing contents may be replaced.
a Open a file for appending.
r+ Open an existing file for reading and writing.
w+ Open for reading and writing; existing contents may be replaced.
a+ Open for reading and appending.

11. File Handling Functions

Function Purpose
fopen() Opens a file.
fclose() Closes a file.
fprintf() Writes formatted data to a file.
fscanf() Reads formatted data from a file.
fputc() Writes a character to a file.
fgetc() Reads a character from a file.
fputs() Writes a string to a file.
fgets() Reads a line/string from a file.

12. Important File Handling Programs

Program 1 – Write Data to a File

#include <stdio.h>

int main()
{
    FILE *fp;

    fp=fopen("notes.txt","w");

    if(fp==NULL)
    {
        printf("File could not be opened.");
        return 1;
    }

    fprintf(fp,"Welcome to Kashish Study Hub.\n");
    fprintf(fp,"C Programming Unit 5.");

    fclose(fp);

    printf("Data written successfully.");

    return 0;
}

Program 2 – Read Data from a File

#include <stdio.h>

int main()
{
    FILE *fp;
    char ch;

    fp=fopen("notes.txt","r");

    if(fp==NULL)
    {
        printf("File could not be opened.");
        return 1;
    }

    while((ch=fgetc(fp)) != EOF)
    {
        putchar(ch);
    }

    fclose(fp);

    return 0;
}

Program 3 – Write a String to a File

#include <stdio.h>

int main()
{
    FILE *fp;

    fp=fopen("message.txt","w");

    if(fp==NULL)
    {
        printf("File could not be opened.");
        return 1;
    }

    fputs("C Programming is easy to learn.",fp);

    fclose(fp);

    printf("Data saved successfully.");

    return 0;
}

14. Quick Revision

  • Structure: User-defined type that groups members of possibly different data types.
  • Union: User-defined type whose members share storage.
  • . operator: Used to access a structure member through a structure variable.
  • -> operator: Used to access a structure member through a pointer.
  • FILE *: File stream pointer.
  • fopen(): Opens a file.
  • fclose(): Closes a file.
  • fprintf(): Writes formatted data to a file.
  • fscanf(): Reads formatted data from a file.
  • fgetc(): Reads a character.
  • fputc(): Writes a character.
