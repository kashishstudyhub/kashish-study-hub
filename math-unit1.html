Unit 1: Calculus-I

Rolle's Theorem

If a function f(x) is continuous on [a,b], differentiable on (a,b), and f(a) = f(b), then there exists at least one point c in (a,b) such that f'(c) = 0.

Lagrange's Mean Value Theorem

If f(x) is continuous on [a,b] and differentiable on (a,b), then there exists c in (a,b) such that:

f'(c) = [f(b) - f(a)] / (b - a)

Cauchy's Mean Value Theorem

If f(x) and g(x) are continuous on [a,b] and differentiable on (a,b), then:

f'(c) / g'(c) = [f(b)-f(a)] / [g(b)-g(a)]

Taylor's Series

f(x) = f(a) + (x-a)f'(a) + (x-a)²/2! f''(a) + ...

Taylor series is used to expand a function around a particular point.

Maclaurin's Series

Maclaurin series is a special case of Taylor series where a = 0.

f(x) = f(0) + xf'(0) + x²/2! f''(0) + ...

Indeterminate Forms

Common indeterminate forms are:

0/0, ∞/∞, 0 × ∞, ∞ - ∞, 0⁰, 1∞, ∞⁰

L'Hôpital's Rule

For limits of the form 0/0 or ∞/∞, differentiation of numerator and denominator can be used.

lim f(x)/g(x) = lim f'(x)/g'(x)

Evaluation of Limits

A limit describes the value approached by a function as x approaches a particular value.

Example: lim (x² - 1)/(x - 1), x → 1

Factorization can be used to evaluate such limits.
