1. Functions in C

A function is a block of statements designed to perform a particular task. Functions help divide a large program into smaller and manageable parts.

Advantages of Functions

  • Code becomes easier to understand.
  • Code can be reused.
  • Large programs can be divided into modules.
  • Testing and debugging become easier.
  • Program structure becomes clearer.

Syntax

return_type function_name(parameters)
{
    // statements
}

Example

#include <stdio.h>

void message()
{
    printf("Welcome to C Programming");
}

int main()
{
    message();

    return 0;
}

3. Arguments and Parameters

A parameter is a variable used in a function definition. An argument is the actual value supplied when the function is called. 

int add(int a, int b)
{
    return a + b;
}

int main()
{
    printf("%d", add(5,10));

    return 0;
}
Example:

Here a and b are parameters, while 5 and 10 are arguments.

4. Return Values

The return statement sends a value from a function back to its caller. 

#include <stdio.h>

int square(int n)
{
    return n * n;
}

int main()
{
    int result;

    result = square(6);

    printf("Square = %d", result);

    return 0;
}

5. Recursion

Recursion is a technique in which a function calls itself to solve a problem.

Two Important Parts

  • Base Case: Condition that stops recursion.
  • Recursive Case: Function calls itself again.
Important:

A recursive function must have a suitable stopping condition.

General Structure

void function()
{
    if(condition)
        return;

    function();
}

6. Important Recursion Programs

Factorial Using Recursion

#include <stdio.h>

int factorial(int n)
{
    if(n == 0 || n == 1)
        return 1;

    return n * factorial(n - 1);
}

int main()
{
    int n;

    printf("Enter a number: ");
    scanf("%d", &n);

    printf("Factorial = %d", factorial(n));

    return 0;
}

Sum of Natural Numbers

#include <stdio.h>

int sum(int n)
{
    if(n == 0)
        return 0;

    return n + sum(n - 1);
}

int main()
{
    int n;

    printf("Enter a number: ");
    scanf("%d", &n);

    printf("Sum = %d", sum(n));

    return 0;
}

Fibonacci Series Using Recursion

#include <stdio.h>

int fibonacci(int n)
{
    if(n == 0)
        return 0;

    if(n == 1)
        return 1;

    return fibonacci(n-1) + fibonacci(n-2);
}

int main()
{
    int n,i;

    printf("Enter number of terms: ");
    scanf("%d", &n);

    for(i=0; i<n; i++)
    {
        printf("%d ", fibonacci(i));
    }

    return 0;
}

7. Pointers in C

A pointer is a variable that stores the memory address of another variable.

Example

int x = 10;
int *p;

p = &x;
  • x stores the value 10.
  • &x gives the address of x.
  • p stores the address of x.
  • *p accesses the value at that address.

8. Address and Dereference Operators

Address Operator &

The & operator gives the address of a variable. 

int x = 10;

printf("%p", (void*)&x);

Dereference Operator *

The * operator can access the value stored at the address held by a pointer. 

int x = 10;
int *p = &x;

printf("%d", *p);

9. Important Pointer Programs

Display Value Using Pointer

#include <stdio.h>

int main()
{
    int x = 25;
    int *p = &x;

    printf("Value = %d\n", x);
    printf("Value using pointer = %d", *p);

    return 0;
}

Change Value Using Pointer

#include <stdio.h>

int main()
{
    int x = 10;
    int *p = &x;

    *p = 50;

    printf("New value = %d", x);

    return 0;
}

10. Passing Arguments Using Pointers

A pointer can be passed to a function so that the function can access and modify the original variable through its address.

Swap Two Numbers Using Pointers

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp;

    temp = *a;
    *a = *b;
    *b = temp;
}

int main()
{
    int x = 10;
    int y = 20;

    printf("Before swap: x = %d, y = %d\n", x, y);

    swap(&x, &y);

    printf("After swap: x = %d, y = %d", x, y);

    return 0;
}
