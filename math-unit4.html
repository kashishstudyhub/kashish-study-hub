Unit 4: Vector Spaces

Vector Space

A vector space is a set of vectors together with two operations: vector addition and scalar multiplication.

These operations must satisfy certain properties such as closure, associativity, commutativity and distributive laws.

Example: R² and R³ are vector spaces.

Subspace

A non-empty subset W of a vector space V is called a subspace if it is itself a vector space under the same operations.

For a subspace:

  • u + v must belong to W
  • cu must belong to W
  • Zero vector must belong to W

Linear Combination

A vector is called a linear combination of given vectors if it can be expressed as:

v = c₁v₁ + c₂v₂ + ... + cₙvₙ

Here c₁, c₂, ..., cₙ are scalars.

Linear Dependence

Vectors v₁, v₂, ..., vₙ are linearly dependent if there exist scalars, not all zero, such that:

c₁v₁ + c₂v₂ + ... + cₙvₙ = 0

If a non-trivial linear relation exists, the vectors are linearly dependent.

Linear Independence

Vectors are linearly independent if the equation:

c₁v₁ + c₂v₂ + ... + cₙvₙ = 0

has only the trivial solution:

c₁ = c₂ = ... = cₙ = 0

Basis of a Vector Space

A basis is a set of vectors that is both:

  • Linearly independent
  • Spans the vector space

Example: The standard basis of R² is:

{(1,0), (0,1)}

Dimension

The dimension of a vector space is the number of vectors in its basis.

Example:

dim(R²) = 2

dim(R³) = 3

Linear Transformation

A function T: V → W is called a linear transformation if:

T(u + v) = T(u) + T(v)

and

T(cu) = cT(u)

for all vectors u, v and scalar c.
