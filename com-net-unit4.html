1. 🌐 Network Layer

The Network Layer is the third layer of the OSI reference model. Its main role is to provide communication between different networks and to determine suitable paths for packets.

Main Functions

  • Logical addressing
  • Routing
  • Packet forwarding
  • Internetworking
  • Handling network-level congestion and related issues
Exam Point:

The Network Layer is mainly associated with routing and packet forwarding.

2. ⚙️ Network Layer Design Issues

The Network Layer has to provide an efficient mechanism for moving packets from a source network to a destination network.

Important Design Issues

  • Services provided to the Transport Layer
  • Routing decisions
  • Packet forwarding
  • Addressing
  • Handling different networks
  • Managing traffic efficiently

Routing and Forwarding

Routing is the process of determining a path from source to destination.

Forwarding is the process of sending a packet towards the selected next hop.

Easy Example:

Source → Router A → Router B → Router C → Destination

Routing determines the path, while forwarding moves the packet from one router to the next.

3. 🛣️ Routing

Routing is the process of selecting a suitable path through a network for packets travelling from source to destination.

Objectives of Routing

  • Find an appropriate path.
  • Use network resources efficiently.
  • Reduce unnecessary delay.
  • Handle changes in network conditions.
  • Provide reliable packet delivery paths.

Routing Algorithms

A routing algorithm determines which path or next hop should be used to forward packets.

Two important algorithms in this unit are:

  • Dijkstra's Algorithm
  • Bellman-Ford Algorithm

4. 🔵 Dijkstra's Algorithm

Dijkstra's algorithm is a shortest-path algorithm used to find minimum-cost paths from a selected source node to other nodes in a graph with non-negative edge weights.

Basic Idea

The algorithm repeatedly selects the currently closest unvisited node and uses it to improve the distance estimates of neighbouring nodes.

Steps

  1. Choose the source node.
  2. Assign distance 0 to the source and infinity to other nodes.
  3. Select the unvisited node with the smallest tentative distance.
  4. Update the distances of its neighbouring nodes if a shorter path is found.
  5. Mark the selected node as visited.
  6. Repeat until the required shortest paths are determined.

Example

Suppose:

A → B = 4

A → C = 2

C → B = 1

Then the path A → C → B has total cost:

2 + 1 = 3

which is shorter than the direct path A → B with cost 4.

Important Point

Dijkstra's algorithm is not suitable when negative edge weights are present.

5. 🟢 Bellman-Ford Algorithm

Bellman-Ford is a shortest-path algorithm that can handle graphs containing negative edge weights, provided there is no reachable negative-weight cycle affecting the shortest path calculation.

Basic Idea

The algorithm repeatedly relaxes all edges and improves distance estimates when a shorter path is found.

Steps

  1. Set the source distance to 0.
  2. Set the initial distance of other nodes to infinity.
  3. Relax all edges repeatedly.
  4. After sufficient iterations, check for further improvements.
  5. If an improvement is still possible, a reachable negative-weight cycle may exist.
Exam Point:

Bellman-Ford can detect reachable negative-weight cycles, whereas Dijkstra's algorithm does not provide this capability.

6. 🏢 Hierarchical Routing

Hierarchical routing divides a large network into regions or levels so that routing information can be organized more efficiently.

Need for Hierarchical Routing

  • Large networks contain many routers.
  • Maintaining complete routing information everywhere can be expensive.
  • Hierarchy reduces the amount of routing information that needs to be handled at each level.
Simple Example:

Country → State → City → Local Network

Similarly, a large computer network can be organized into multiple routing regions.

Advantages

  • Reduces routing information.
  • Improves scalability.
  • Makes routing management easier.

7. 📢 Broadcast Routing

Broadcast routing is a method in which a packet or message is delivered to all relevant nodes in a network or broadcast domain.

Applications

  • Network discovery
  • Distribution of information to multiple nodes
  • Service discovery in suitable network environments

Important Consideration

Broadcasting can generate significant network traffic, so efficient techniques are important.

Easy Meaning:

Broadcast = One sender → Many/all relevant receivers.

8. 👥 Multicast Routing

Multicast routing is used when a sender needs to deliver data to a selected group of receivers rather than to every node.

Basic Idea

One sender → Selected group of receivers

Advantages

  • Reduces unnecessary duplicate transmissions.
  • Efficient for group communication.
  • Useful when multiple receivers need the same data.

Broadcast vs Multicast

Broadcast Multicast
Data is sent to all relevant receivers. Data is sent to a selected group.
May create more traffic. Can reduce unnecessary traffic.
One-to-all style communication. One-to-group style communication.

9. 📊 Dijkstra vs Bellman-Ford

Feature Dijkstra Bellman-Ford
Shortest Path Yes Yes
Negative Edge Weights Not supported Supported
Basic Approach Select closest tentative node and relax neighbours Repeatedly relax all edges
Negative Cycle Detection Not designed for this Can detect reachable negative-weight cycles
